# Website Profil Padukuhan Ngrancah

Website profil resmi **Padukuhan Ngrancah, Sriharjo, Imogiri, Bantul**.

## Tech Stack

- React + Vite
- Tailwind CSS

## Menjalankan Project

```bash
npm install
npm run dev
```

Buka browser di alamat yang ditampilkan di terminal (biasanya `http://localhost:5173`).

## Build Production

```bash
npm run build
npm run preview
```

## Mengubah Konten

Semua teks dan data website ada di:

```
src/data/content.js
```

Ganti foto placeholder dengan foto asli padukuhan melalui URL atau file di folder `public/`.
